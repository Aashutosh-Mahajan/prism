How the dashboard works

PRISM builds a local code index. Its context engine supplies selected source and relationships to your coding agent. The graph makes those facts visible.

The CLI, MCP and hooks keep working independently of this browser. Context previews do not inject anything into a benchmark session.

Managed comparisons need enforced session isolation, effective write permissions and actual usage counters. This release supports context retrieval, the existing graph, evidence import, comparisons and patch exports. Automated coding runs are unavailable until an adapter passes those gates.
