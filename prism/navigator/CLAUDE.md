# Navigator rules

- Shared library operations serve CLI, MCP, hooks and viewer.
- Budget every rendered and JSON output; default context cap is 2,000 estimates.
- Use verified source matching the manifest; report unavailable or stale text.
- Mark exact lists exhaustive only when every indexed site was checked.
- Low confidence must retain explicit recovery guidance.
- Read only missing ranges; never pretend a header means omitted code was sent.
- Remember only ranges actually delivered; reset after compaction.
- Checked patches never edit user source. Preserve bytes and CRLF.
- Preserve cache engine fingerprints and cross-surface parity.
- Ranking and tie-breaking are deterministic. Protect recall with replay checks.
